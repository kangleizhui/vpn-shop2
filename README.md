# 云商城 · 机场订阅商城

多服务器 Hiddify 面板接入、自动建号、聚合订阅、共享流量池、用量大屏。

---

## 一、环境要求

| 项目 | 要求 |
|---|---|
| PHP | 8.1 及以上（推荐 8.3） |
| 扩展 | `pdo_mysql`、`curl`、`mbstring`、`openssl`、`json`（SQLite 模式还需 `pdo_sqlite`） |
| Web | Nginx（宝塔）/ Apache |
| 数据库 | MySQL 5.7+ / 8.0，或 SQLite（免配置） |
| 目录权限 | `app/` 可写（安装时写配置），`data/` 可写（SQLite 与日志） |

宝塔面板：**软件商店 → PHP 8.3 → 设置 → 安装扩展**，勾选 `pdo_mysql`、`curl`、`mbstring`、`openssl`。同时**禁用函数**里删掉 `putenv`、`proc_open` 一般不影响本项目。

## 二、宝塔部署（5 步）

### 1. 上传解压

宝塔 → 网站 → 添加站点（PHP 8.3，不建数据库也行）→ 文件 → 进入站点目录 → 上传 `vpn-shop.zip` → 解压。

解压后目录结构：

```
你的站点根目录/
├── app/                 # 后端（不能被公网访问）
│   ├── bootstrap.php
│   ├── hiddify.php
│   ├── payment.php
│   ├── pool.php
│   ├── submerge.php
│   └── config.sample.php
├── public/              # ← 网站运行目录
│   ├── index.php
│   ├── install.php
│   └── assets/
├── bin/
│   └── sync_usage.php   # 用量定时同步
├── install.lock         # 安装后自动生成
└── README.md
```

### 2. 设置运行目录

宝塔 → 网站 → 设置 → **网站目录** → 运行目录选择 `/public` → 保存。

### 3. 设置伪静态

宝塔 → 网站 → 设置 → **伪静态**，粘贴：

```nginx
location / {
    try_files $uri $uri/ /index.php?$query_string;
}
```

（Apache 环境无需配置，`public/.htaccess` 已内置规则。）

### 4. 建数据库并安装

宝塔 → 数据库 → 添加数据库，记下：数据库名、用户名、密码。

浏览器访问：

```
https://你的域名/install.php
```

按向导填写：

- 数据库类型：MySQL（推荐）或 SQLite（免填数据库信息）
- 数据库地址：`127.0.0.1`，端口 `3306`
- 数据库名 / 用户名 / 密码：上一步创建的信息
- 站点名称、管理员账号、管理员密码（≥8 位）

点「开始安装」，成功后会创建全部数据表并写入 3 个默认套餐。

> **安装完成后删除 `public/install.php`**，防止他人重装。

### 5. 添加用量同步任务

宝塔 → 计划任务 → 添加任务：

| 项 | 值 |
|---|---|
| 任务类型 | Shell 脚本 |
| 任务名称 | 订阅用量同步 |
| 执行周期 | N 分钟 → 5 分钟 |
| 脚本内容 | `php /www/wwwroot/你的域名/bin/sync_usage.php` |

再添加一条（到期 / 流量提醒邮件）：

| 项 | 值 |
|---|---|
| 任务类型 | Shell 脚本 |
| 任务名称 | 到期流量提醒 |
| 执行周期 | N 分钟 → 30 分钟 |
| 脚本内容 | `php /www/wwwroot/你的域名/bin/notify.php` |

> 路径换成你的实际站点路径。5 分钟任务负责：从各台 Hiddify 拉取已用流量、更新共享流量池、超量/到期自动停用、续费自动恢复；30 分钟任务负责：到期前 3 天 / 已到期 / 流量 80% / 95% 的提醒邮件。

## 三、后台使用

访问 `https://你的域名/admin/login`，用安装时设置的管理员账号登录。

### 添加服务器

后台 → **服务器** → 添加：

| 字段 | 说明 |
|---|---|
| 管理地址 | Hiddify 超管链接，形如 `https://面板域名/后台路径/超管UUID` |
| 密码 | 面板管理员密码 |
| 地区 | 留空自动检测（按 IP 归属地），也可手填「香港」「美国-洛杉矶」 |
| 名称 | 留空自动生成「地区-城市」 |

保存后系统会自动登录面板、读取订阅路径、检测地区。**只需这两个字段**，订阅地址由系统自动推导。

### 套餐

后台 → **套餐**：

- `single`：用户选一台服务器，只发该服务器的订阅
- `all`：用户买一次，系统在所有已上架服务器各建一个号，再合成**一个聚合订阅链接**（v2rayN / sing-box / Clash 自动识别 UA）

### 订阅池 / 数据大屏

- `/admin/subs`：共享流量池，按邮箱聚合，总流量 = 所有节点合计；可手动「全部立即同步」
- `/admin`：概览即数据大屏，用量、收入、趋势、服务器状态一屏看完
- **编辑用户**：订阅池和订单列表每行都有「编辑」，可改邮箱、备注、流量上限、到期时间、启用/停用，保存后立即推送到所有节点面板（等同 Hiddify 后台改用户）
- **添加用户**：订阅池/订单页右上角「添加用户」，管理员可不经支付直接开通（全地区共享或单地区），填邮箱、套餐名、流量、天数即可

### 订阅详情页（给用户的）

每个订阅都有一个友好页面，不要再直接把订阅链接发进浏览器（会显示乱码，那是给客户端用的格式）：

```
https://你的域名/s/<订阅token>
```

页面内容：已用/剩余流量、到期时间、剩余天数、节点数、**订阅二维码**、一键复制订阅链接。
后台「订阅池」「数据大屏」里的「订阅」按钮已直接指向这个页面，订单页也有入口。

### 邮件提醒（到期 / 流量）

后台 → **设置 → 邮件通知**：

| 字段 | 说明 |
|---|---|
| 启用 | 勾选后才会发信 |
| SMTP 服务器 | QQ 邮箱填 `smtp.qq.com` |
| 端口 | SSL 用 `465`，STARTTLS 用 `587` |
| 加密方式 | 一般选 SSL |
| 邮箱账号 | 你的发件邮箱 |
| 授权码 | QQ 邮箱「设置 → 账户 → 开启 SMTP」生成的授权码（不是登录密码，会加密存储） |
| 发件人地址 | 留空则用邮箱账号 |

填好后点「发送测试邮件」验证，成功后再勾选启用。
触发规则（每条只发一次，续费后自动重置）：到期前 3 天、已到期、流量 80%、流量 95%。
也可以点「立即检查并发送提醒」手动跑一次。

### 支付

后台 → **设置 → 支付设置**，三大类分别展开，每种方式独立填写自己的参数。

**1. 易支付**（一套配置，启用后收银台同时出现支付宝 / 微信）

接口地址、商户 PID、商户密钥；回调 `/notify`

**2. 支付宝官方**（每种方式单独填 AppID / 应用私钥 / 支付宝公钥 / 网关）

| 方式 | 需签约产品 | 额外参数 |
|---|---|---|
| 电脑网站支付 | 电脑网站支付 | — |
| 手机网站支付 | 手机网站支付 | — |
| 当面付（扫码） | 当面付 | 门店 ID（选填） |

回调 `/notify/alipay`，三种方式共用这个地址，系统会逐个密钥验签。

**3. 微信支付官方 API v3**（每种场景单独填商户参数）

| 方式 | 需要填写 | 说明 |
|---|---|---|
| Native 扫码 | AppID、MchID、证书序列号、商户私钥、APIv3 密钥 | PC 二维码 |
| H5 支付 | 同上 + H5 支付域名 | 手机浏览器 |
| JSAPI 支付 | 公众号 AppID、AppSecret、MchID、证书序列号、商户私钥、APIv3 密钥 | 微信内，自动网页授权取 openid |

> 新版商户如果只拿到「微信支付公钥ID + 公钥」，在对应方式里填入这两个选填字段即可，系统会自动用公钥验签；不填则走平台证书自动下载。

回调 `/notify/wechat`。

- 密钥类字段加密存储；留空表示不修改
- 私钥支持直接粘贴裸 base64，自动补 PEM 头
- 前台只显示「已启用 + 配置完整」的方式，并按三大类分组
- `test_mode = 1` 时管理员可模拟支付

## 四、用户侧

用户**无需注册**：

1. 首页选套餐 → 填邮箱 → 下单 → 支付
2. 支付成功后自动建号并显示订阅链接
3. 以后在「我的订阅」输入购买邮箱即可查回订阅链接

### 内置使用教程页

项目自带 `/tutorial` 页面，首页左上角菜单和购买流程第 3 步都有入口，内容包括：

- Windows / Android / macOS / iOS 客户端下载与安装
- 订阅链接导入、选节点、连接的完整步骤
- 常见问题（连不上、节点不更新、多设备、速度慢）

把安装包放进 `public/downloads/`（文件名固定）就会优先走本站下载；没放则自动跳转 Hiddify 官方 GitHub 发布页，不会出现死链。

## 六、常见问题

**Q：首页 404 / 只有首页能打开**
伪静态没配。按第 3 步添加 `try_files` 规则。

**Q：安装页提示数据库连接失败**
检查数据库名/用户名/密码；MySQL 8 若用 `caching_sha2_password`，在宝塔数据库里把用户密码改成 `mysql_native_password` 兼容模式，或确认 PHP 的 `pdo_mysql` 已启用。

**Q：后台加服务器提示登录失败**
管理地址必须是**超管链接**（含 `/后台路径/UUID`），不是面板首页；密码是面板管理员密码。

**Q：订阅点开是空白/报错**
该服务器面板上的用户已过期或被禁用，在后台「订阅池」点一次「全部立即同步」，或检查服务器状态。

**Q：用量一直不更新**
计划任务没跑。手动执行一次 `php /站点路径/bin/sync_usage.php` 看输出。

**Q：提醒邮件发不出去**
先在后台点「发送测试邮件」，看返回的具体错误：
- `密码被拒绝 535` → 授权码不对，QQ 邮箱要用「授权码」不是登录密码
- `连接失败` → 服务器/端口不对，或被主机商封了 465（换 587 + STARTTLS）
- 收件箱没有 → 看垃圾箱，或在发件邮箱的「已发送」里确认

**Q：打开订阅链接是乱码**
那是客户端格式（base64），正常现象。发给用户看请用 `/s/<token>` 订阅页，里面带二维码和用量。

## 七、升级与备份

- 备份：打包整个站点目录 + 导出数据库即可（SQLite 模式备份 `data/shop.db`）
- 升级：覆盖 `app/` 与 `public/` 下文件，**保留 `app/config.php` 和 `install.lock`**
